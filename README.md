# CalendarWeb

Сайт «Космос календаря» — планер в браузере: те же события, задачи,
привычки, напоминания и календари, что в планере на компьютере и телефоне, и
тот же аккаунт. Сайт — ещё одно устройство аккаунта на сервере синхронизации
([CalendarServer](https://github.com/SayxZero/CalendarServer)); страницу и
связь с сервером даёт бэкенд
([CalendarWebServer](https://github.com/SayxZero/CalendarWebServer)).

Без сборки и без сторонних библиотек: `site/` — это и есть сайт, ES-модули и
CSS как они есть. Тесты логики — `node --test`.

Страниц две: на `/` — презентация проекта, на `/app/` — сам планер.

## Что умеет

- **Экраны** — год, месяц, неделя (1, 3, 5 или 7 дней), день, повестка,
  задачи, напоминания, привычки, статистика; поиск по событиям и задачам.
- **События** — время или весь день, многодневные, календарь и свой цвет,
  место, описание, отменённые (зачёркнуты и без напоминаний).
- **Повторения** — каждый день, неделю (по дням недели), месяц (по числу или
  по дню недели), год; интервал; без конца, N раз или до даты. Правка, перенос и
  удаление спрашивают: только это повторение или вся серия.
- **Задачи** — срок с временем и без, подзадачи, «выполнить вместе с
  подзадачами», «не выполнена», повторяющиеся задачи переезжают на следующий
  срок, журнал выполнений; группы по сроку или по статусу; порядок задач с
  одним сроком.
- **Напоминания** — у событий и задач (несколько, каждое — уведомление или
  будильник, у записи без времени — «за N дней, в ЧЧ:ММ»), и напоминания сами
  по себе (экран «Напоминания»), с повтором и выключением. Пока вкладка открыта,
  сайт показывает уведомление браузера или звонит будильником (мелодии
  планера, свои мелодии аккаунта, нарастающая громкость, «Отложить»);
  выключенный здесь будильник не звонит и на других устройствах.
- **Календари** — цвет, видимость, звёздочка (панель под экранами: нажатие —
  показать или скрыть, удержание — только этот), порядок, удаление с переносом
  записей; импорт и экспорт ICS (один календарь — один файл).
- **Совместный доступ** — открыть свой календарь (чтение, правка,
  настраиваемый), участники и их права, ссылки (одноразовые и многоразовые, со
  сроком) — и для сайта, и для планера; добавить чужой календарь по ссылке;
  отказаться от доступа. Конфликты общего календаря («только чтение», «запись
  удалена владельцем — вернуть?») показываются, а не теряются.
- **Привычки** — отметка за сегодня, отчёт за 30 дней, правка дней, удаление
  с возвратом.
- **Палитры** — все палитры планера, своя палитра, загрузка и сохранение
  файла палитры планера.
- **Данные** — резервная копия в формате планера (JSON) и её загрузка, свои
  мелодии (файл обрезается до двух минут), «Выгрузить всё заново».
- **Две раскладки.** На компьютере — боковая панель (аккаунт, экраны,
  мини-календарь, календари), перетаскивание событий мышью, выделение времени
  для нового события. На телефоне — шапка, выдвижное меню (кнопкой и свайпом
  от левого края), круглая «+», свайп по периоду, полноэкранные редакторы.
- **Легко для браузера** — записи аккаунта в браузере не хранятся: страница
  берёт их с сервера при каждом открытии, правки уходят через 3 секунды и при
  уходе со страницы. Сайт работает рядом с сервером синхронизации, режима
  «нет связи» у него нет.

## Страница-презентация

`/` — обычная прокручиваемая страница, минималистичная: без градиентов, без
фиолетового, без «экранов», переключаемых колесом. Сверху вниз:

- название, слоган «Приведите дела в порядок» и три плашки версий: Web
  («Открыть»), Android и Desktop («В разработке») — на широком экране всё это
  видно сразу, без прокрутки;
- возможности — у каждой ролик с настоящим интерфейсом и пара строк текста; на
  компьютере ролик и текст чередуются слева и справа, на телефоне идут
  столбиком; ролик играет, пока виден, а по нажатию открывается крупно;
- уровни доступа на горизонте планеты: «Попробовать бесплатно» и «Полная версия»
  на месяц и на год — у каждого подпись, кнопка и цена; год выделен и несёт бейдж
  «-N%», когда он дешевле месяца;
- подвал: слева «Юридическая информация» — столбец значков со значениями, без
  подписей, справа логотип и название.

Страница обращается к посетителю на «вы».

**Графика и ролики** лежат в `site/img` и `site/video`, а делаются из исходников
в [`media/`](media/README.md): картинки — ChatGPT по промптам, ролики — записью
настоящих планера, телефона и сайта, анимации — Blender. После новой версии всё
обновляется одной командой:

```bash
node media/make.mjs
```

**Юридические данные** — не в сайте: их перезаписало бы обновление. Подвал
берёт их у бэкенда (`GET /web/legal`), а тот — из `legal.json` своей папки
данных; туда же кладётся файл договора оферты (README CalendarWebServer,
«Папка данных»). Пока файла нет, подвала на странице нет. **Цены** — там же, в
`pricing.json` (`GET /web/pricing`); пока цена не заполнена, на плашке написано
«Цена появится позже». Оплаты пока нет: у полной версии вместо кнопки — «Оплата
в разработке».

## Запуск

Сайт открывают через бэкенд — он отдаёт `site/` и передаёт запросы серверу
синхронизации. В рабочей копии зонтика:

```bat
CalendarWebServer\run-web.bat                         :: http://localhost:8780 (планер — /app/), сервер 127.0.0.1:8765
CalendarWebServer\run-web.bat -u 127.0.0.1:8766       :: с тестовым сервером
```

Вход — логином и паролем аккаунта сервера синхронизации; «Создать аккаунт»
регистрирует новый, если сервер это разрешает. Ссылка на общий календарь
вида `https://<сайт>/app/#join=<токен>` открывает его добавление; ссылки
прежнего вида, `https://<сайт>/#join=<токен>`, презентация передаёт
планеру.

Клавиши: `←` `→` — период, `T` — сегодня, `N` — новое событие, `/` — поиск,
`Esc` — закрыть окно, `Ctrl+Enter` — сохранить.

Браузеры — современные (ES-модули, `structuredClone`): Chrome,
Edge, Firefox, Safari последних лет, на телефоне тоже.

## Тесты

```bash
npm test          # то же: node --test "tests/*.test.js"
```

62 теста: даты, движок повторений, напоминания (упаковка, перевод между
видами), формат записей планера (в том числе неизвестные поля), хранилище
(выполнение задач, отдельные повторения, календари, привычки, общий доступ),
обмен двух устройств через поддельный сервер, ICS туда и обратно, ссылки
общего доступа.

## Структура

```
site/
  index.html                  презентация: css/landing.css, js/landing.js, img/logo.svg
  img/features/               картинки возможностей (кладутся сюда)
  app/index.html              планер; manifest.webmanifest, img/logo.svg
  css/app.css                 оформление планера: палитра — переменные CSS; ПК и телефон
  js/main.js                  запуск планера: вход, первый обмен, окно
  js/model/                   модель планера без DOM: даты, повторения, напоминания,
                              записи (формат JsonIo), палитры, общий доступ, слова
  js/core/                    хранилище (DataStore), обмен (SyncEngine/SyncService),
                              API, ICS, напоминания вкладки, мелодии
  js/ui/                      окно, экраны (views/), редакторы, карточки, настройки
tests/                        node --test
tools/planner-sandbox/        вход в песочницу планера без его окна (для проверок)
```

Как всё устроено — [DesDoc.md](DesDoc.md).
